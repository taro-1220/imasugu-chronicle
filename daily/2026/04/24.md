## 反省
- CTA ボタンが「見た目は存在するが反応しない」状態は認証失敗後の loading フラグが解除されていないパターンとして典型的

## 学んだこと
- 認証系の失敗パスは「成功パスと同等に loading / disabled フラグをリセットする」ことを必ず確認する
- write path guard は ID が null/undefined のまま書き込まれるケースを upstream で止めるのが最善
